About the model

Catchment Area Neural Network Model

A multilayer perceptron that estimates subcatchment runoff from geometric and hydrological properties, benchmarked against SWMM simulations.

Eight subcatchment features are standardized using training set statistics, then processed through two hidden layers of eight neurons to a single output neuron. Each neuron computes an affine combination with bias and applies ReLU activation. The network was trained using the Adam optimizer with mean squared error loss.

    The equations behind the network

    Features

    The network reads eight properties of each subcatchment from the SWMM model, in SI units (a US model's widths and storage depths are converted first):

    Imperviousness (%)
    Share of the land surface, excluding LID, that is impervious.
    Width (m)
    Characteristic width of the overland flow path.
    Slope (%)
    Average surface slope.
    Manning's n, impervious
    Roughness for overland flow over the impervious area.
    Manning's n, pervious
    Roughness for overland flow over the pervious area.
    Depression storage, impervious (mm)
    Depth of water held back on the impervious area.
    Depression storage, pervious (mm)
    Depth of water held back on the pervious area.
    Impervious area without storage (%)
    Share of the impervious area without depression storage.

    Subcatchment area is excluded from the input vector: the network was trained exclusively on 5 ha catchments, so predictions represent runoff for standard 5 ha reference units.

    Surrogate modeling context

    Neural network surrogates provide near-instantaneous runoff estimates for catchment screening and sensitivity sweeps, bypassing full numerical differential equation solvers when evaluating many design variations.
