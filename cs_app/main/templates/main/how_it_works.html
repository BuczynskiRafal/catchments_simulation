How it works

How the simulation works

Every result on this site comes from the EPA Storm Water Management Model. This page shows the equations it solves for a subcatchment and explains what a parameter sweep and the neural network do with them.

Running a tool

What happens when you run a tool

  1. 1

    Load the model

    Your .inp file is stored for your session. It is never changed.

  2. Once for every value

    1. 2

      Write one value

      swmmio writes the next value of the chosen parameter into a temporary copy of the model.

    2. 3

      Run SWMM

      pyswmm runs the SWMM engine on that copy and reads the subcatchment's runoff, infiltration and evaporation.

  3. 4

    Collect and compare

    One row per run goes into the charts, the table and the downloads.

A timeseries analysis keeps every time step of each run instead of its totals; the comparison runs the model once and asks the neural network for the same runoff.

{# ── 2. Runoff model ─────────────────────────────────────────── #}

Runoff model

The runoff model: a nonlinear reservoir

SWMM treats a subcatchment as a shallow, sloped surface that stores rain and releases it. It splits the surface into up to three sub-areas — pervious ground, impervious surface with depression storage and impervious surface without it — and follows the depth of water ponded on each of them.

Water balance of a sub-area:

{% verbatim %}
\frac{\mathrm{d}d}{\mathrm{d}t} = i - e - f - q
(1)
{% endverbatim %}

Runoff starts once the depth exceeds the depression storage. SWMM then treats the sheet of water as flow in a very wide channel and applies Manning's equation:

{% verbatim %}
Q = \frac{1}{n}\, W\, (d - d_s)^{5/3}\, S^{1/2}
(2)
{% endverbatim %}

Per unit of area this is

{% verbatim %}
q = \frac{Q}{A} = \alpha\,(d - d_s)^{5/3}, \qquad \alpha = \frac{W\,S^{1/2}}{A\,n}
(3)
{% endverbatim %}

so the depth follows one ordinary differential equation — a nonlinear reservoir: the fuller it is, the faster it drains.

{% verbatim %}
\frac{\mathrm{d}d}{\mathrm{d}t} = i - e - f - \alpha\,(d - d_s)^{5/3}
(4)
{% endverbatim %}

The three sub-areas share the rain but not the losses:

{% verbatim %}
A_{\mathrm{perv}} = (1 - I)\,A, \qquad A_{\mathrm{imp}} = I\,(1 - z)\,A, \qquad A_{0} = I\,z\,A
(5)
Q(t) = \sum_k q_k(t)\,A_k
(6)

Only the pervious sub-area infiltrates (f = 0 elsewhere), and A_0 has no depression storage (d_s = 0), so it runs off from the first drop. Both impervious sub-areas use the roughness n_{\mathrm{imp}} and the whole impervious area I\,A in \alpha; the pervious one uses n_{\mathrm{perv}} and (1 - I)\,A.

Equations are written in SI units; in US customary units Manning's equation carries the factor 1.49. S is the slope as a fraction (PercSlope / 100).

Infiltration

Infiltration

On the pervious sub-area part of the water infiltrates into the soil. The example model uses the Modified Green–Ampt method; SWMM also offers Horton and Curve Number infiltration, and the tools run whichever method your model names in its INFILTRATION option.

f = K_s \left( 1 + \frac{(\psi + d)\,\theta_d}{F} \right)
(7)

K_s is the saturated hydraulic conductivity, \psi the suction head at the wetting front, \theta_d the initial moisture deficit, F the infiltration accumulated so far and d the ponded depth. Until the surface layer saturates, everything that arrives infiltrates. For rain heavier than K_s that happens once F reaches

F_s = \frac{K_s\,(\psi + d)\,\theta_d}{i - K_s}
(8)

From then on SWMM advances F over each time step \Delta t with the integrated form of (7), solved by Newton's method, and takes f = (F_2 - F_1) / \Delta t:

F_2 - F_1 - c\,\ln\frac{F_2 + c}{F_1 + c} = K_s\,\Delta t, \qquad c = (\psi + d)\,\theta_d
(9)

Numerical solution

How the equations are solved

Equation (4) has no closed-form solution. Over each runoff time step (WET_STEP while it rains or water is ponded, DRY_STEP otherwise) SWMM takes evaporation and infiltration from the available water, fills the depression storage, and then advances the depth with a fifth-order Runge–Kutta method (Cash–Karp) that adapts its internal step to keep the error below 10^{-4}. The runoff rate of the step is \alpha\,(d - d_s)^{5/3} at its end.

d(t + \Delta t) = d(t) + \int_{t}^{t + \Delta t} \left[\, i - e - f - \alpha\,(d - d_s)^{5/3} \right] \mathrm{d}\tau
(10)

Parameter sweep

What a sweep measures

A parameter sweep repeats the simulation with one parameter p changed and everything else fixed:

y_j = \mathcal{M}(p_j), \qquad p_j = p_{\mathrm{start}} + j\,\Delta p, \qquad j = 0, \dots, N - 1
(11)

Each run is reduced to a few numbers:

V = \int_0^T Q\,\mathrm{d}t, \qquad Q_p = \max_t Q(t)
(12)

the runoff volume and the peak runoff rate, together with the infiltrated and evaporated volumes. The results summarise the response as the relative change between the first and the last value:

\Delta = \frac{y_{N-1} - y_0}{\lvert y_0 \rvert} \cdot 100\,\%
(13)

The timeseries tool reports the time to peak and integrates the hydrograph with the trapezoidal rule:

t_p = \operatorname*{arg\,max}_t Q(t) - t_0, \qquad V \approx \sum_k \tfrac{1}{2}\,(Q_k + Q_{k+1})\,(t_{k+1} - t_k)
(14)

{# ── 8. Neural network ───────────────────────────────────────── #} {% verbatim %}

Neural network

The neural network

The comparison tool estimates the runoff volume of each subcatchment with a small fully connected network instead of a simulation. It reads eight properties of the subcatchment:

x = \left( I,\; W,\; S,\; n_{\mathrm{imp}},\; n_{\mathrm{perv}},\; d_{s,\mathrm{imp}},\; d_{s,\mathrm{perv}},\; z \right)
(15)

standardises them with the mean \mu and standard deviation \sigma of its training data and passes them through two hidden layers of eight neurons:

\tilde{x} = \frac{x - \mu}{\sigma}, \qquad h^{(1)} = \mathrm{ReLU}\!\left(W_1 \tilde{x} + b_1\right), \qquad h^{(2)} = \mathrm{ReLU}\!\left(W_2 h^{(1)} + b_2\right)
(16)
\hat{V} = \mathrm{ReLU}\!\left(w_3^{\top} h^{(2)} + b_3\right), \qquad \mathrm{ReLU}(u) = \max(0, u)
(17)

The weights were fitted with the Adam optimiser to minimise the mean squared error against SWMM runs of the example model. The network therefore knows nothing about the rainfall or the area: it is reliable only for subcatchments and storms close to the ones it was trained on. The comparison reports how far it is from SWMM:

\begin{gathered} \mathrm{MAE} = \frac{1}{N} \sum_k \lvert \hat{V}_k - V_k \rvert, \qquad \mathrm{RMSE} = \sqrt{\frac{1}{N} \sum_k (\hat{V}_k - V_k)^2}, \\[0.5em] \mathrm{MAPE} = \frac{100\,\%}{N} \sum_k \left\lvert \frac{\hat{V}_k - V_k}{V_k} \right\rvert \end{gathered}
(18)
{% endverbatim %}
