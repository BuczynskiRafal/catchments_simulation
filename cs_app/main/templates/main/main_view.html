Documentation

The Python package

Everything this site does comes from the open-source catchment_simulation package, which drives the Storm Water Management Model (SWMM) through pyswmm and swmmio. Its FeaturesSimulation class holds all the methods.

The constructor takes two arguments: subcatchment_id, the identifier of the subcatchment you want to simulate, and raw_file, the path to the SWMM input file. It raises FileNotFoundError when the file does not exist and ValueError when the subcatchment is not in the model. Use it as a context manager (with statement) so the temporary files it creates are removed afterwards.

Install it with pip:

pip install catchment-simulation

Simulation methods

Every method runs SWMM on a temporary copy of your model, so the original file is never changed. Sweeps return one row per simulated value.

Model and single runs

get_section(section="subcatchments")
Returns the given section of the input file as a pandas DataFrame.
copy_file(copy=None, suffix="copy")
Copies the input file, adding a suffix to its name. Copies the raw file by default.
calculate()
Runs one simulation and returns summary statistics for the subcatchment as a dict with the keys runoff, peak_runoff_rate, infiltration and evaporation.
calculate_timeseries()
Runs one simulation and collects every time step. Returns a DataFrame with a DatetimeIndex and the columns rainfall, runoff, infiltration_loss, evaporation_loss and runon. Rainfall and infiltration loss are in mm/h (in/h in US-unit models), evaporation loss in mm/day (in/day), runoff and runon in the model's FLOW_UNITS.

Parameter sweeps

simulate_subcatchment(feature, start, stop, step)
Varies any subcatchment feature over a range and returns summary statistics for each value.
simulate_subcatchment_timeseries(feature, start, stop, step)
Like simulate_subcatchment, but keeps the full timeseries of every run: returns a dict[float, pd.DataFrame] keyed by parameter value.
simulate_area(start=1, stop=10, step=1)
Sweeps the subcatchment area.
simulate_percent_impervious(start=0, stop=100, step=10)
Sweeps the percentage of impervious area.
simulate_percent_slope(start=0, stop=100, step=10)
Sweeps the percent slope.
simulate_width(start=0, stop=100, step=10)
Sweeps the characteristic width of the overland flow path.
simulate_curb_length(start=0, stop=100, step=10)
Sweeps the total curb length.
simulate_percent_zero_imperv(start=0, stop=100, step=10)
Sweeps the percentage of impervious area with no depression storage.

Literature values

simulate_manning_n(param)
Runs the subcatchment with Manning's n values from the literature (McCuen et al., 1996). Takes no range.
simulate_n_imperv() · simulate_n_perv()
Manning's n for the impervious or the pervious area.
simulate_destore(param)
Runs the subcatchment with depression storage depths from the literature (ASCE, 1992). Takes no range.
simulate_s_imperv() · simulate_s_perv()
Depression storage depth for the impervious or the pervious area.

Analysis functions

The catchment_simulation.analysis module reads the DataFrame returned by calculate_timeseries().

time_to_peak(timeseries, column="runoff")
Time from the first time step to the peak value, as a pd.Timedelta.
runoff_volume(timeseries, column="runoff", start=None, end=None)
Total volume from integrating the flow rate over time (trapezoidal rule), optionally between start and end. The result is in flow units × seconds, so cubic metres for a model in CMS.

Sweep the slope

from catchment_simulation import FeaturesSimulation

with FeaturesSimulation(subcatchment_id="S1", raw_file="example.inp") as model:
    df = model.simulate_percent_slope(start=1, stop=100, step=1)

Collect a timeseries and its metrics

This is how the storm at the top of the page was computed.

from catchment_simulation import FeaturesSimulation, runoff_volume, time_to_peak

with FeaturesSimulation(subcatchment_id="S1", raw_file="example.inp") as model:
    ts = model.calculate_timeseries()

ttp = time_to_peak(ts, column="runoff")
vol = runoff_volume(ts, column="runoff")

Sweep a parameter and keep every timeseries

from catchment_simulation import FeaturesSimulation

with FeaturesSimulation(subcatchment_id="S1", raw_file="example.inp") as model:
    results = model.simulate_subcatchment_timeseries(
        feature="PercImperv", start=0, stop=100, step=10
    )
