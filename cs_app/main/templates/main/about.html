About

About

Catchment Simulation shows how a stormwater subcatchment responds when you change one of its parameters, without writing a line of code.

What it is

An open-source Python package, catchment_simulation, and this web app built on it. Both run the EPA Storm Water Management Model (SWMM) for one subcatchment of your model while varying a parameter such as slope, area, width, imperviousness, Manning's n or depression storage.

Who it is for

Hydrologists, civil and environmental engineers, urban planners and students working on stormwater management. Use it to check how sensitive a design is to a parameter, compare scenarios before changing a model, or show a class how a catchment reacts to rain.

How it works

  1. 1

    Load a model

    Upload a SWMM .inp file or use the bundled sample. Your original file is never changed.

  2. 2

    Change one parameter

    swmmio writes each value of the range into a temporary copy of the model.

  3. 3

    Run SWMM

    pyswmm runs the SWMM engine for every copy and collects runoff, infiltration and evaporation.

  4. 4

    Read the answer

    Charts, tables and metrics show the response; export the numbers to Excel or CSV.
